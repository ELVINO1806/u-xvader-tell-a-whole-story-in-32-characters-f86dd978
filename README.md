## The entry

A Wi-Fi name that reads like a tiny leaving note for a shared household: one person walks out, and the password — the small shared thing everyone relied on — walks out with them. Two short sentences, one move, and the whole story is there: who left, what changed, and who is locked out now.

The name fits the 32-character limit for a Wi-Fi network name, and it works because the second sentence reuses the first one's verb: moving out and the password moving too are the same event, told twice.

`main.py` writes the entry to `/output/entry.txt` when run with Python 3 (standard library only, no network):

```sh
python3 main.py
```
